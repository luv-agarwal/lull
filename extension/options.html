Strict mode is on. Adding sites is instant; removing or loosening waits 60 seconds.

Sites

Each site blocks its subdomains too. Paste as many as you like — one per line, or separated by commas or spaces. Chrome asks once per add to let Lull show its block page on those sites; Lull never gets access to any other site.

    Exceptions

    Never blocked, even inside a blocked site — for example music.youtube.com while youtube.com is blocked.

      Schedules

      Sites set to "Always" block all the time. A site on a focus window blocks only inside it; outside it Lull removes the rule completely.

        Strict mode

        Hides the 5-minute pass. Removing a site, adding an exception, editing a schedule or turning strict mode off first needs a 60-second wait.

        Import / export

        Plain text, one site per line. =host blocks only that exact host, !host is an exception, site @Schedule name assigns a schedule.

        Lull works inside Chrome only. It makes no network requests, has no analytics and adds nothing to the pages you visit. Your list syncs through your own Chrome sync; stats stay on this computer.
